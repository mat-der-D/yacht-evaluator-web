# Astro トップページ生成用プロンプト

## 指示

以下の条件を厳守して、Astro を用いたトップページ（`/`）を実装してください。

### 前提
- フレームワークは **Astro**
- 対象は **Webアプリへの入口となるトップページのみ**
- `/app` に既存の React 製 Web アプリが存在する前提
- about ページは存在しない
- 説明文は最小限にする

### ページの目的（最重要）
- ユーザーを迷わせず `/app` に送ること
- 読ませない
- 考えさせない
- 行動を 1 つに絞る

### ページ構成（厳守）

#### 1. タイトル
表示テキスト：
```
ヨット 局面評価
```
- サブタイトルは置かない

#### 2. 一言説明（1行のみ）
表示テキスト：
```
ヨットの局面を評価するツール
```

#### 3. スクリーンショット
- 画像は 1 枚のみ
- 中央配置
- レスポンシブ対応
- 装飾・説明文は付けない
- `alt` は簡潔に設定する

#### 4. メインボタン（唯一のCTA）
表示テキスト：
```
使ってみる
```
- `/app` へのリンク
- ページ内で最も目立つデザイン
- 他のボタン・リンクは置かない

#### 5. フッター（最小）
表示テキスト（1行のみ）：
```
解析の背景は補完的な同人誌にまとめています。
```
- 外部リンクとして設定する
- フッター以外に説明文を追加しない

### デザイン方針
- シンプル
- 余白を多めに取る
- 色数は最小限
- 説明している感を出さない

### やってはいけないこと
- 長文説明
- about 的な文章
- 開発背景・思想の記述
- 機能一覧
- Q&A
- 複数導線
- SEO 狙いの不自然な文章

### 出力要件
- Astro のページファイルとして完成したコードを出力
- 必要最低限の HTML / CSS のみ
- JavaScript 不要
- コンポーネント分割不要

### ゴール
- ページを開いて 3 秒以内に
  「使ってみる」以外の選択肢が存在しない状態
